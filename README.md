# ЛР 2: диагностика привода по току (Sensorless Drive Diagnosis)

По 48 числам, посчитанным из тока двигателя, модель определяет, в каком из 11 состояний двигатель.

## Структура проекта

```
проект_2-3/
├── data/
│   └── Sensorless_drive_diagnosis.txt   исходные данные
├── src/
│   ├── common.py          общий код: load_data, split, prepare, evaluate, get_model, outliers
│   ├── example.py         образец скрипта — с него начинать свой
│   ├── data_passport.py   паспорт данных
│   └── g<N>_<фамилия>.py  скрипты участников, по одному на гипотезу
├── figures/               картинки (создаётся само)
└── reports/               таблицы (создаётся само)
```

## Как начать

1. Скачать репозиторий:

   ```
   git clone <ссылка на репозиторий в GitVerse>
   ```

2. Установить библиотеки (один раз):

   ```
   pip install pandas numpy scikit-learn matplotlib scipy
   ```

3. Проверить, что файл данных лежит в `data/Sensorless_drive_diagnosis.txt`.

4. Запустить пример из папки `src`:

   ```
   cd src
   python example.py
   ```

   Должна напечататься accuracy, а в папке `figures/` появиться картинка `example.png`.
   Сделай скриншот и пришли в общий чат.

В PyCharm: открыть папку проекта, нажать правой кнопкой на `example.py` → Run.

## Как написать свой скрипт

1. Скопировать `example.py` и назвать по шаблону `g<номер гипотезы>_<фамилия>.py`, например `g3_degtyareva.py`.
2. Все общие вещи брать только из `common.py`:

   ```python
   from common import load_data, split, prepare, evaluate, get_model, outliers
   ```

3. Самим не делать разбиение и нормализацию: никаких `train_test_split` и `StandardScaler` в своих скриптах.
4. Картинки сохранять в `figures/`, таблицы — в `reports/`.

## Правила

- Перед каждым запуском — `git pull`: `common.py` мог измениться.
- `common.py` меняют только Мелине и Сергей Д. Нужно что-то поменять — напиши им.
- Изменился `common.py` — перезапусти свой скрипт.
- После дня 3 `common.py` заморожен.
- Числа в отчёты и слайды — только из общего прогона всех скриптов.

Полный план и задачи каждого — в документе «ЛР2_кто_что_делает».
